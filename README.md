# README

## Instalação

Para instalar todas as dependências necessárias, execute o comando:

```bash
pip install -r requirements.txt
```
Após isso, basta rodar os scripts do notebook em ordem. Esses passos (instalação via pip e execução do notebook) são necessários apenas para a análise.

## Protótipo Web

Caso o usuário queira rodar o protótipo web, basta rodar:

```bash
fastapi run main.py
```

E acessar no `localhost` na porta que foi direcionada pelo comando.
